# Code Of Conduct

CueFetch welcomes precise, respectful collaboration around the project.

## Expected Behavior

- Discuss the work and evidence, not a person's motives or identity.
- Give direct technical criticism without insults, harassment, or pile-ons.
- Respect privacy, copyright, access boundaries, and responsible-use limits.
- Remove private URLs, credentials, cookies, personal paths, and identifying data
  from public reports.
- Accept a clear project-scope decision even when a proposal is declined.

## Unacceptable Behavior

Harassment, threats, discrimination, sexualized conduct, deliberate exposure of
private information, malicious disruption, and instructions intended to evade
lawful access controls are not acceptable in project spaces.

## Reporting Conduct Problems

Use GitHub's built-in content-reporting and blocking tools for platform abuse. For
a project-specific concern, open a minimal issue asking for a private maintainer
channel without publishing sensitive details. Security vulnerabilities use the
private process in [SECURITY.md](SECURITY.md).

Maintainers may edit, hide, lock, or remove project content that violates these
boundaries. This document does not create a response-time, investigation, or
appeal commitment.
