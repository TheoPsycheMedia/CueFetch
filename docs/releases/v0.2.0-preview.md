# CueFetch 0.2.0 Preview

CueFetch 0.2.0 Preview introduces a new recommendation-first interface while
strengthening the download plan, privacy, compatibility, and release contracts
needed for a public open-source preview.

## Highlights

- New Liquid Orbit workflow for analyzing a link, choosing output quality,
  reviewing the destination, and following download progress
- Native Liquid Glass on macOS 26 with adaptive material fallbacks for macOS 14
  through macOS 25
- Compatible 1080p MP4 recommendation that keeps video and audio together for
  common Apple and editing workflows
- Source-derived quality stops with higher-resolution and custom formats still
  available when explicitly selected
- Download Details sheet for codecs, conversion warnings, captions, profiles,
  destinations, command preview, and recovery guidance
- General-purpose Editing, Audio, Archive, and Short Clips workflow profiles

## Reliability and privacy

- One validated download plan is shared by the visible preview and subprocess
  execution
- Single-item URL intake prevents a reviewed video from silently expanding into
  a playlist
- Completion requires both the final-path marker and a real output file
- Recent links remain session-only, receipt URLs are redacted, and Safari cookie
  access is job-scoped
- The standard MP4 path uses strict H.264 video and AAC audio selectors for
  QuickTime-compatible playback

## Compatibility

- macOS 14 or later
- Apple silicon and Intel Macs
- `yt-dlp` installed locally
- FFmpeg for the standard MP4 and audio presets and formats that require merging

The bundle identifier changed to `com.theopsychemedia.CueFetch`. macOS may treat
this as a separate app from 0.1.0 Preview, and preferences from that earlier
preview might not carry forward automatically.

## Distribution notice

This preview DMG is ad-hoc signed and is not notarized by Apple. Verify the
attached SHA-256 checksum before opening it. macOS may require an explicit trust
decision. The GitHub release includes the DMG, checksum file, and an artifact
manifest identifying the source commit and signing/notarization status.

After verifying the checksum, open the DMG and drag CueFetch to Applications.
If macOS blocks the first launch, Control-click CueFetch in Applications, choose
Open, and confirm the prompt. Do not disable Gatekeeper globally.

Only download media you are authorized to access and follow the source site's
terms and applicable law.
